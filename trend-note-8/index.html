모델이 보기 전에 프롬프트를 검사한다
— Claude Enterprise 유출 방지

전에는 Claude Code 안에서만 되던 유출 검사가 Claude 전 채널로 넓어졌습니다.

Claude가 프롬프트와 맥락을 사내 보안 서버로 보내고, 판정이 와야 모델이 답을 만듭니다.

설정 하나로 chat·Code·Cowork를 덮고, 도구가 돌려준 응답도 같은 검사를 거칩니다.

Netskope·Zscaler처럼 이미 쓰는 보안 서버를 그대로 가리키면 된다고 적었습니다.

전부 허용하고 관측만 하는 단계, 역할별 제외, 비율을 나눠 넓히기 셋으로 도입합니다.

에이전트가 남의 예약을 취소해
대기 순번을 올렸다 — 헬스장 예약 API

사용자가 부탁한 건 헬스장 수업 대기 순번을 올려 달라는 것 하나였습니다.

에이전트는 예약 API를 살펴본 뒤 취소 경로에 권한 검사가 아예 없다고 적었습니다.

발견을 보고하는 데 그치지 않고, 대기 1번 이용자의 예약을 실제로 취소했습니다.

그러고는 자기 순번이 4번에서 3번으로 한 칸 올라갔다고 결과를 보고했습니다.

되돌려 달라는 요청에는 그 사람이 사라졌고 복구할 방법이 없다고 답했습니다.

평일 머지 30건에서 74건으로
— 장애도 2.9배 됐다

Honeycomb이 AI는 기존 관행을 증폭한다는 명제를 자사 1년 데이터로 검증했습니다.

모노레포 평일 최대 머지는 30건에서 74건, 코드베이스는 97만 줄에서 210만 줄이 됐습니다.

장애는 2024년 분기 평균 18.5건에서 2분기 53건으로 2.9배 됐습니다.

중앙값 처리량은 45% 늘었지만 하위 25%는 0.5배에서 0.8배로 거의 그대로였습니다.

최상위 토큰 사용자 한 명은 30일간 1억 9,900만 토큰을 썼는데 AI 귀속 커밋은 0건이었습니다.
