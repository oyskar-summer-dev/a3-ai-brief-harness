개발 조직에서는 코드를 AI에게 맡기는 단계를 지나, 「AI가 쓴 코드를 어떻게 믿고 합칠까」를 팀 규칙과 AI 리뷰로 저마다 풀어 본 글이 많습니다.

개발 바깥에서는 디자이너가 개발 PR을 직접 고쳐 넘기고, 기획자가 개발자 없이 업무 비서 앱을 만들어 쓰는 등 직군의 경계를 넘는 사례가 나왔습니다.

사람과 AI가 같은 문서를 보게 하는 지식베이스도 여럿 나왔습니다. 기획 문서나 스펙을 한곳에 모으는 데까지는 비슷했지만, 그 원본이 낡지 않게 지키는 방법은 조직마다 달랐습니다.

AI와 일하는 방식

「사람이 읽었나」 대신 「무엇이 잡아낼까」
— Claude Code 팀이 공개한 여러 겹 코드 리뷰

제품 코드의 약 90%를 Claude가 쓰는 Claude Code 팀이, 에이전트가 쏟아내는 변경을 어떻게 리뷰하는지 공개했습니다.

6월부터 9월 사이 합쳐진 PR은 두 배 넘게 늘었는데, 되돌려야 했던 비율은 오히려 40% 넘게 줄었다고 밝혔습니다.

이렇게 된 이유는 리뷰에서 묻는 질문을 바꾼 것이라고 이야기합니다. 「사람이 코드를 읽었나」 대신 「이 변경에서 무엇이 잘못될 수 있고 어떤 검사가 그걸 잡아낼까」를 묻고, 읽는 일 대부분을 기계에 넘겨 사람의 시간은 위험한 곳에 쓴다고 밝혔습니다.

어디가 위험한지는 변경마다 매기는 등급으로 가립니다. 문서 수정 같은 낮은 위험은 그 저장소를 맡은 팀처럼 미리 정해 둔 사람이 올리고 자동 검사가 통과하면 사람 승인 없이 합쳐지고, 일반 제품 변경은 한 사람, 가장 위험한 코드는 두 사람이 봅니다.

에이전트끼리 리뷰가 끝없이 돌지 않게 거는 상한, 지난 사고 사례로 AI 리뷰어를 날마다 고치는 방법까지 담겨 있으니 자세한 내용은 원문에서 확인해 보세요.

Section 205 — 12
AI와 일하는 방식

무작위로 정한 AI의 권유를 전문가들이
86% 따랐다 — 그러고도 절반 넘게 자기 판단이라 여긴 Anthropic 실험

AI 에이전트와 일해도 중요한 판단은 결국 사람이 내린다고들 하는데, Anthropic이 정말 그런지 실험해 봤습니다.

통계 분석 전문가 50명에게 Claude Code와 함께 농업 협동조합의 자문 서비스를 늘릴지 접을지 분석하게 했습니다. 분석 중에는 「면적당 수확량으로 잴지, 비용당 수확량으로 잴지」처럼 둘 다 말이 되는 선택이 네 번 나오는데, 연구진은 그때마다 Claude가 어느 쪽을 권할지 전문가 몰래 무작위로 정해 두었습니다.

4가지의 선택을 통틀어 전문가들이 Claude가 권한 쪽을 고른 비율은 86%였습니다. Claude가 아무 영향을 주지 않았다면 반반 안팎이었을 값입니다.

나중에 왜 그렇게 골랐는지 물으니, 77%가 답 가운데 한 번 이상 Claude의 논리를 그대로 되풀이했습니다. 그런데 그것이 Claude에게서 나온 생각이라고 밝힌 사람은 15%뿐이었습니다. 「마지막 권고(자문 서비스를 늘릴지 접을지)는 Claude의 권고에 가깝나요, 당신의 권고에 가깝나요?」라는 물음에는 52%가 「내 권고에 더 가깝다」고 답했습니다.

연구진은 여러 팀이 같은 AI에 기대어 같은 결론을 내면 서로 따로 확인한 것처럼 보여도 실은 AI 한 곳의 선호일 수 있다고 짚었습니다.

모델

같은 구독 한도로 더 많은 일을
— 최상위 모델보다 싸고 빠른 OpenAI의 GPT-6.1 Terra

OpenAI가 GPT-6.1 Terra를 내놓았습니다. 자사 최상위 모델인 GPT-6 Astra·GPT-6.1 Sol보다 싸고 빠르게 쓰도록 만든 모델입니다.

청구서를 읽어 회계 프로그램에 옮겨 적거나, 기술 도면을 해석하고 양식을 채우는 것처럼, 문서와 화면을 보며 컴퓨터로 처리하는 반복 업무에 맞췄다고 설명합니다.

API 값은 이전 Terra와 GPT-6.1 Sol보다 50% 낮고, ChatGPT Work와 Codex에서는 같은 사용량 한도로 이전보다 더 많은 일을 처리할 수 있습니다.

전문 업무를 재는 평가(Agents' Last Exam)에서는 최상위 모델 GPT-6 Astra와 비슷한 점수를 토큰당 10분의 1 값으로 냈다는 회사 측정입니다.

다만 가장 복잡한 코딩 작업에는 여전히 Sol이나 Astra를 쓰는 편이 낫다고 OpenAI도 안내합니다.

Section 307 — 12
모델

공개 모델이 코딩 에이전트 평가에서
Opus 5.5 턱밑까지 — Moonshot AI의 Kimi K3.1 Pro

Moonshot AI가 Kimi K3.1 Pro를 공개했습니다. 모델 파일(가중치)을 통째로 내려받아 자기 서버에서 돌릴 수 있게 푸는 공개 모델(오픈 웨이트)로, 전체 파일은 11월 4일까지 풀 예정입니다.

회사 발표로는 코딩 에이전트가 터미널에서 실제 과제를 얼마나 해내는지 재는 평가에서 65.7%를 받아, Claude Opus 5.5(66.4%)와 거의 같고 GPT-6 Astra(58.2%)보다는 높았습니다.

능력이 오른 만큼 해킹에 쓰일 위험도 따져, 학습 데이터에서 사이버 공격 관련 내용을 일부러 걸러 공격 능력을 낮춘 뒤 공개한다고 밝혔습니다.

가상의 사람이 몇 초 만에 쓰러지던 보행 시뮬레이터를 스스로 고쳐 가며 걷게 만든 긴 작업 사례와, 3D 모델 만들기·재무 분석 예시까지 담겨 있으니 자세한 내용은 원문에서 확인해 보세요.

모델

COBOL을 다른 언어로 옮기는
정확도 5.4%에서 86.6%로 — OpenAI, AI가 배울 자료가 적은 언어의 코딩 실력을 따로 쟀다

OpenAI가 COBOL·Fortran·Visual Basic처럼 AI가 배울 코드와 문서가 적은 언어에서 최신 모델의 코딩 실력을 따로 재 공개했습니다.

이런 언어는 은행·카드 결제 같은 핵심 시스템을 떠받치고 있어, 고치거나 다른 언어로 옮길 때 기존 동작을 그대로 지켜야 합니다.

COBOL 프로그램을 Java·Python 같은 언어로 옮기는 평가에서 GPT-6.1 Sol의 정확도는 이전 모델(GPT-5.6 Sol)의 5.4%에서 86.6%로 뛰었습니다. 결과가 바이트 하나까지 같아야 통과로 치는 깐깐한 평가입니다.

다만 운영 중인 시스템에 쓰려면 여전히 전문가 검토와 업무 규칙을 반영한 테스트가 필요하다고 덧붙였습니다.

20개 언어로 데이터베이스 엔진을 처음부터 짓게 한 또 하나의 평가와 언어별 점수까지 담겨 있으니 자세한 내용은 원문에서 확인해 보세요.

도구

사용 한도를 아끼는 /usage 한 줄 고침
— Claude Code 2.1.300~2.1.312

Claude Code 2.1.300부터 2.1.312까지의 주요 업데이트 소식입니다.

/usage는 이제 사용량을 많이 쓰는 원인마다 한 줄짜리 고칠 방법을 붙이고, f 키 하나로 그 고침을 바로 적용합니다.

Pro·Max 요금제에서 오래 쉰 대화를 다시 열면 5시간 한도를 꽤 쓰게 될 때 미리 알려 주고, 새 대화로 시작해도 이전 대화를 언급하면 Claude가 그 대화를 찾아볼 수 있다고 안내합니다.

claude -p로 스크립트나 서버에서 Claude를 돌릴 때도, 이제 Claude가 일을 나눠 맡기면 지금까지의 대화를 그대로 이어받는 하위 에이전트(포크)가 기본으로 뜹니다.

AI가 읽는 정보

숫자를 다 지어낸 통계 5만 쪽이
7개월 동안 ChatGPT 답변의 근거로 — 논문·투자 리서치까지 번진 실험

AI 답변의 출처를 추적하는 회사 Peec AI의 연구자가, 숫자를 전부 지어낸 통계 사이트를 일부러 만들어 AI가 이를 어떻게 받아들이는지 실험했습니다.

AI로 통계 페이지 5만 개를 하루 만에, 약 30달러를 들여 만들었고 숫자는 하나도 확인하지 않았습니다.

Google 검색에서는 금세 거의 보이지 않게 됐지만, ChatGPT는 7개월이 지나도록 이 가짜 페이지를 계속 찾아 근거로 썼습니다. 그는 ChatGPT가 질문과 관련 있는지는 따지지만 숫자가 맞는지는 확인하지 않기 때문이라고 설명합니다.

그렇게 쓰인 가짜 숫자는 학술 논문과 카타르 최대 금융그룹의 투자 리서치에까지 인용됐고, 그는 이 과정을 「인용 세탁」이라고 불렀습니다.

AI가 통계를 즐겨 가져다 쓰는 이유와, 숫자를 제대로 확인해 통계 페이지를 만드는 요령까지 담겨 있으니 자세한 내용은 원문에서 확인해 보세요.

산업

Anthropic, 상장 신청서 S-1을 냈다
— 나스닥 종목 코드 「ANT」, 공모 규모와 가격은 아직 미정

Anthropic이 미국 증시 상장을 위한 증권 신고서 S-1(미국에서 상장하려는 회사가 증권거래위원회에 내는 서류)을 냈다고 밝혔습니다.

상장할 주식은 A종 보통주이고, 나스닥 글로벌 셀렉트 시장에 올릴 계획입니다.

이번 발표는 짧은 공시 안내문이라 실적이나 기업 가치 같은 숫자는 담기지 않았고, 예비 투자설명서는 준비되는 대로 Goldman Sachs와 Morgan Stanley를 통해 받을 수 있다고 안내했습니다.
