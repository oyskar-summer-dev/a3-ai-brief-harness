모델

Luna 값이 5분의 1로
— 재원은 모델이 다시 쓴 자사 커널

OpenAI가 7월 30일 GPT-5.6 세 등급 중 둘의 값을 내렸습니다.

Luna는 100만 토큰당 입력 $1에서 $0.20으로, 5분의 1이 됐습니다.

출력도 $6에서 $1.20으로 같은 폭이라 두 항목 모두 80% 인하입니다.

중간 등급 Terra는 20% 내렸고 상위 Sol은 $5·$30 그대로입니다.

자사 모델 Sol에 서빙 코드를 다시 쓰게 해 비용을 20% 줄인 것이 재원이라고 밝혔습니다.

같은 일에 토큰 17% 덜 쓴다
— Gemini Flash 3종 동시 공개

구글이 주력 3.6 Flash, 초경량 3.5 Flash-Lite, 보안 특화 3.5 Flash Cyber를 함께 냈습니다.

3.6 Flash는 출력 토큰을 17% 적게 쓰고 값은 입력 $1.50·출력 $7.50입니다.

코딩 평가(DeepSWE)는 37%에서 49%로, 컴퓨터 조작 평가는 78.4%에서 83.0%로 올랐습니다.

보안 특화 Cyber는 공격에도 쓰일 수 있어 정부와 신뢰 파트너에게만 제한 공개됩니다.

도구

에이전트를 조직 단위로 굴린다
— 개인·공용 공간을 나눈 하네스 (⭐9.9k)

구성원마다 개인 작업 공간을 두고 그 위에 팀 공용 공간을 얹는 에이전트 하네스입니다.

Y Combinator 계열 YC Software가 MIT 라이선스로 공개했습니다(⭐9.9k).

Slack과 웹을 같은 신원으로 묶고, 스킬을 git 저장소에서 가져와 팀이 공유합니다.

하네스를 고정하지 않아 Pi·OpenCode·Codex·Claude Code 사이를 오가며 고릅니다.

에이전트가 그 사람의 계정 권한으로 움직여, 모든 동작이 그 사람 이름으로 남습니다.

도구

MCP 서버가 대화를 기억하지 않는다
— 요청 하나로 끝내는 2.0

AI에게 외부 도구를 붙이는 표준 규격 MCP가 7월 28일 자 개정판을 냈습니다.

요청 하나에 필요한 것을 모두 담아 보내고, 서버는 앞선 요청을 기억하지 않습니다.

서버가 상태를 들고 있지 않아 재시작하거나 여러 대로 늘리기 쉬운 구조가 됩니다.

핵심 밖 기능은 확장으로 뺐고 장시간 작업·스킬 배포·대화 안 화면 셋이 먼저 정리됐습니다.

도구 설명은 믿을 만한 서버에서 온 것이 아니면 신뢰하지 말라고 못 박았습니다.

도구

테스트가 없으면 시작도 못 한다
— Anthropic의 코드 이전 6단계

Anthropic이 한 달간 패키지 10개를 옮긴 경험을 6단계로 정리했습니다.

착수 조건은 옮긴 코드가 원본과 같게 도는지 자동으로 판정할 테스트입니다.

이것이 없으면 작업이 언제 끝났는지 판단할 기준 자체가 없다고 말합니다.

Bun을 Rust로 옮긴 사례는 2주에 100만 줄, 병합 뒤 회귀 19건이 나와 모두 고쳤습니다.

미뤄둔 이전 작업이 있다면 이제 계산을 다시 해볼 때라는 말로 글을 맺습니다.

Section 409 — 12
정책

금지를 주장한 적 없다 — Anthropic이
직접 그은 세 개의 선

Anthropic이 7월 27일 오픈웨이트 모델에 대한 입장을 정리해 냈습니다.

위험한 역량이 없는 공개 모델은 실행 비용 외에 값이 들지 않는 공공재라고 표현했습니다.

지지한다고 밝힌 것은 칩 수출 통제, 산업 규모 증류 단속, 의무 안전 시험 셋입니다.

안전 시험은 사이버·생물 위험과 모델이 지시를 따르는지를 출시 전에 재자는 것입니다.

효과를 보려면 시험이 전 세계 단위여야 해서 중국도 동참해야 한다고 인정했습니다.

Section 510 — 12
기타

매니저 한 명이 엔지니어 서른 명
— 회사마다 답이 달랐다

여러 회사 리더와 나눈 대화를 바탕으로 조직 구조를 비교한 글입니다.

OpenAI는 한 프로젝트에 2-4명을 붙이고, 매니저 한 명이 엔지니어 서른 명을 봅니다.

Anthropic은 피자 두 판이면 점심이 되는 5-8명 팀을 그대로 두고 전담 QA도 없습니다.

Anthropic 쪽은 AI가 낸 결과를 리뷰하는 일이 가장 가치 있는 역량이 됐다고 말합니다.

저자는 완벽한 조직 구조는 없고 회사마다 맞는 것이 다르다는 말로 맺습니다.

버튼과 폼은 사라진다 — 에이전트가
주 사용자가 되는 2030년

PostHog이 2030년을 기준으로 제품을 어떻게 다시 짤지 공유했습니다.

사람에게 남는 일을 판단·결정과 이해·신뢰 두 가지로 봅니다.

화면을 남길지는 사람이 신뢰·판단 때문에 보는가, 행동하려고 보는가로 가릅니다.

전면 재설계 대신 데스크톱 앱 한 곳부터 2030년 형태로 넓히는 절충을 택했습니다.

2030년에 남을 회사는 그래야만 하기 훨씬 전에 짓기 시작한 곳이라는 말로 맺습니다.
