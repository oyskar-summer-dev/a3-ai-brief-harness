Section 103 — 11
모델

3주 만에 후속이 나오고 값은 절반
— Gemini 3.7 Flash

Google이 코딩과 에이전트용 주력 모델을 내놨습니다. 직전 3.6 Flash 출시 3주 만입니다.

공개된 다섯 평가가 모두 올랐고, 코딩 평가는 34.4%에서 43.6%로 뛰었습니다.

구독자용 개인 에이전트 Spark도 같은 날부터 이 모델로 바뀌어 160개국에 열렸습니다.

도입가는 100만 토큰당 입력 0.75달러와 출력 3.75달러로 직전 모델의 절반입니다.

다만 12월 31일까지만이고, 이듬해부터는 입력 1.50달러와 출력 7.50달러가 됩니다.

Section 204 — 11
도구

같은 토큰으로 더 멀리 가는 법
— Anthropic이 밝힌 세션 비용 구조

Anthropic이 Claude Code 세션에서 토큰이 어디로 새는지 정리한 가이드를 냈습니다.

값을 가르는 것은 캐시입니다. 이미 보낸 내용을 다시 읽을 때는 입력가의 10분의 1만 듭니다.

캐시는 요청 맨 앞부터 맞아야 해서, 도중에 모델이나 추론 강도를 바꾸면 그 뒤가 전부 다시 채워집니다.

대화를 통째로 요약하는 /compact는 캐시를 깨지만, 최근 대화만 잘라내는 /rewind는 앞이 그대로라 캐시가 남습니다.

나머지 절약 요령은 원문에 명령 단위로 정리돼 있으니 꼭 확인해 보시길 권합니다.

Section 205 — 11
도구

서브에이전트가 대화를 통째로 물려받는다
— Claude Code 2.1.228~234

서브에이전트 분기가 기본으로 켜지면서 대화 전체와 캐시를 함께 물려받습니다.

긴 세션에서 화면이 느려지던 문제와 특이한 문자가 섞인 메시지의 렌더링 지연이 고쳐졌습니다.

골뱅이 기호로 다른 세션을 이름으로 지목하는 입력 방식도 새로 붙었습니다.

Claude API 사용법이 담긴 내장 스킬을 부를 때 실리는 양이 20만 토큰대에서 2만 5천으로 줄었습니다.

MCP 서버 설정을 진단하면 환경변수로 감춰 둔 키가 실제 값으로 화면에 찍히던 문제도 고쳐졌습니다.

Windows에서 같은 파일을 다르게 표기해 경로 검사를 빠져나가던 구멍도 막혔습니다.

Section 306 — 11
연구

같은 모델을 써도 격차는 8.3배
— OpenAI 기업 고객 실사용 데이터

OpenAI가 기업 고객 실사용 데이터로 낸 보고서입니다. 표본은 1,000만 건이 넘는 메시지입니다.

상위 10% 기업 직원은 중간 기업 직원보다 8.3배 많이 뽑아냅니다. 1월엔 2.6배였습니다.

기업이 쓰는 출력 가운데 에이전트가 만든 몫이 64%로, 작년 8월 거의 0에서 올라왔습니다.

격차는 도구와 나란히 벌어졌습니다. 반복 지시를 묶어 두는 스킬을 매주 쓰는 비율이 19% 대 3%였습니다.

쓰는 사람도 엔지니어링 밖에서 더 빨리 늡니다. 2월 이후 법무 직군은 108배, 엔지니어링은 5배 늘었습니다.

Section 307 — 11
연구

같은 모델을 여럿 띄우면 실수도 똑같이 한다
— Anthropic 연구

에이전트를 여러 대 굴리면 한 대일 때 없던 고장이 난다는 연구입니다.

연구는 원인 하나로 서로 너무 닮은 점을 듭니다. 같은 모델을 여럿 띄우면 성향이 갈리지 않습니다.

같은 일을 시키자 30대 중 18대가 똑같은 브랜치 이름을 지었고, 협력이 이득인 게임에서도 하나같이 배신했습니다.

거짓이 섞인 정보를 가려내는 비율은 Mythos 5가 85%, Sonnet 계열은 62%로 갈렸습니다.

조율할 방법을 주지 않자 초당 30번씩 찔러 대는 방식으로 몰려, 작업 요청 240만 건 중 117건만 통과했습니다.

Anthropic은 조정 능력이 지능과 함께 저절로 생기지는 않는다고 못 박았습니다.

Section 408 — 11
이슈·보안

감춰 둔 추론을 약한 형제 모델이 받아 적는다
— 트레이스 탈취

요즘 모델은 답하기 전에 속으로 생각하는데, 그 사고 기록은 회사 자산이라 암호로 감춰 돌려줍니다.

이 연구는 감춰진 사고 기록을 받아, 같은 회사의 더 약한 모델에게 이전 턴의 제 생각인 것처럼 건넵니다.

같은 계열이면 암호 키를 공유하기 때문에 약한 모델은 그것을 읽을 수 있습니다.

그 모델의 안전장치를 우회하게 만들어 강한 모델의 사고를 받아 적게 하는 것이 공격의 전부입니다.

Claude 4.6에서는 그 기능을 없앴지만 Haiku 4.5에서는 여전히 작동한다고 이야기합니다.

모델이 자기 사고 기록을 유난히 신뢰하는 성질을 이용해 그 안에 지시를 심는 변형도 가능하다고 짚었습니다.

Section 509 — 11
정책

Claude가 쓴 글에 표식이 박힌다
— 방식과 한계를 밝힌 공식 설명

Anthropic이 8월 2일 이후 나오는 모든 Claude 모델의 글에 표식을 심습니다.

유럽연합 인공지능법 때문이며, 7월에 주요 AI 회사들과 함께 그 이행 규약에 서명했습니다.

표식은 단어를 고르는 순간에 들어갑니다. 비밀 키로 다음 단어 후보를 두 편 갈라, 한쪽이 조금 더 자주 나오게 기울입니다.

한 번으로는 티가 안 납니다. 그런데 글이 길어질수록 그 한쪽이 쌓여, 같은 키로 되짚으면 통계로 드러납니다.

그래서 짧은 글은 표식이 모일 틈이 없어 판정이 안 되고, 통째로 다시 쓰면 사라집니다.

사람이 쓴 글을 Claude가 교정만 한 경우도 원문이 대부분이라 거의 감지되지 않습니다.

Section 510 — 11
정책

탐지되려고 단어를 고른다 — 워터마크에
대한 정면 반박

존 그루버가 Anthropic 발표 이틀 뒤에 정면 반박 글을 올렸습니다.

문제 삼은 것은 단어가 뽑히는 이유입니다. 글이 좋아지는 쪽이 아니라 찾기 쉬운 쪽으로 기운다는 지적입니다.

어느 쪽을 골라도 뜻이 같은 자리란 없으며 단어 하나하나가 제 몫을 한다고 봅니다.

Claude가 쓴 코드에는 정확성 때문에 표식을 거의 안 거는데, 글은 함부로 손대도 되냐고 따집니다.

비밀 키는 만든 쪽만 쥐고 있어, 어느 단어가 표식 탓에 뽑혔는지 글쓴이도 모릅니다.

유럽연합 규약이라는 근거는 인정하면서도 규제 자체를 거칠게 비난하고, 결국 정직한 사람만 걸릴 것이라고 보았습니다.
